4 Tester une valeur
À utiliser : if et ==

if permet d'exécuter une instruction seulement si une condition est vraie. L'opérateur == vérifie si deux valeurs sont égales.

Exemple

x = 3

if x == 3:
    print("Bravo")
Affiche
Bravo
Attention à la différence

x = 3 donne la valeur 3 à la variable x.

x == 3 vérifie si la valeur de x est égale à 3.

À faire

Créez une variable nombre contenant 10. Si nombre est égal à 10, affichez :

Le nombre est bien égal à 10

17 Compter les nombres pairs
À utiliser : boucle, %, if et compteur

L'opérateur % donne le reste d'une division. Un nombre est pair si le reste de sa division par 2 est égal à 0.

Exemple

nombre = 8

if nombre % 2 == 0:
    print("Nombre pair")
